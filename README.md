# Сплит — учебный проект по управлению программными проектами

Веб-приложение для учёта и разделения общих расходов в группе: поездки, съёмная квартира, мероприятия. Концепция выбрана в фазе 1 по результатам нечёткого коллективного TOPSIS и коллективного МАИ.

## Внешние ресурсы

Задачи, их исполнители, оценки и затраченное время ведутся в [таск-трекере](https://github.com/users/OWNER/projects/N) (GitHub Projects). У задач с несколькими исполнителями есть подзадачи на каждого участника.

## Навигация по репозиторию

| Папка | Фаза | Содержание |
|-------|------|------------|
| [`phase1/`](./phase1/) | Фаза 1. Выбор концепции проекта | концепции и критерии, экспертные оценки, нечёткий коллективный TOPSIS, чёткий коллективный МАИ |
| [`report/`](./report/) | Отчёты по фазам | итоги каждой из фаз |

## Статус

- **Фаза 1**: готова. Добавлены файлы с расчётами [TOPSIS](./phase1/topsis.xlsx) и [МАИ](./phase1/mai.xlsx) и [отчёт](./report/Отчёт%20по%20фазе%201.docx), где разобраны результаты обоих методов и обоснован выбор концепции.
